# 🪑 Seating Arrangement Plan

A simple web app to create and manage seating arrangements for classrooms, exams & events.

## ✨ Features
- Interactive seating layout
- Add / Remove seats
- Easy to use on mobile & desktop

## 🛠️ Tech Used
HTML, CSS, JavaScript

## 🚀 How to Use
1. Open `index.html`
2. Add names
3. Arrange seats
